# Accessibility baseline (cross-stack)

Planet Components keep a **minimum** a11y contract across stacks. Platform idioms differ; semantics must not.

## Required for interactive controls

| Concern | Web (React/Vue) | React Native | Flutter | Android View | iOS SwiftUI | Mini Program |
| --- | --- | --- | --- | --- | --- | --- |
| Role | `role` / native element | `accessibilityRole` | `Semantics` | `ViewCompat` / `contentDescription` | `.accessibility*` | `aria-role` / `aria-label` when supported |
| Name | `aria-label` or visible text | `accessibilityLabel` | `label` | `contentDescription` | `accessibilityLabel` | `aria-label` |
| Disabled | `disabled` + `aria-disabled` | `accessibilityState.disabled` | `enabled: false` | `setEnabled(false)` | `.disabled()` | `disabled` |
| Checked / selected | `aria-checked` / `aria-selected` | `accessibilityState` | `selected` / `toggled` | `selected` / `checked` | traits | `aria-checked` when supported |
| Busy / loading | `aria-busy` | announce or state | Semantics | announce | announcement | — |
| Dialog | `role="dialog"` + `aria-modal` | modal a11y | barrier dismiss | Dialog | `.sheet` / alert | catchtouch + focus |

## Component minimums

- **Button / IconButton / TextLink / Chip**: activatable; disabled state exposed; loading → `aria-busy` (Web) or equivalent.
- **Switch / Checkbox / Radio**: exposes checked + disabled; loading does not lose name.
- **Progress**: valuemin / valuemax / valuenow (or percent announced).
- **Tabs / BottomTab / ChildSwitcher / SegmentedControl**: selected tab announced.
- **Modal / OptionSheet / LoadingDialog**: dialog role + dismiss control labeled.
- **TopBar back**: labeled control (not icon-only without name).
- **Toast / Alert / Notification**: `role="status"` or live region where platform allows.
- **Collapse**: `aria-expanded` / equivalent.
- **StarRating**: valuemin/max/now or per-star labels.
- **SearchBar**: labeled text field.

## Motion

| Stack | Behavior |
| --- | --- |
| Web / Mini | `prefers-reduced-motion: reduce` disables transitions (see CSS / `theme.wxss`) |
| React Native | `useReduceMotion` + `AccessibilityInfo` (Switch thumb/spinner duration → 0) |
| Flutter | `MediaQuery.disableAnimationsOf` skips press lift animation on Button |
| iOS | Prefer system Reduce Motion; avoid decorative loops |

Token: `motion.rules.respectPrefersReducedMotion`.

## Automation

- React Web: `vitest` + `axe-core` (`react-web/library/tests/a11y.test.js`).
- RN/Flutter/Android/iOS: manual + Semantics/`accessibility*` on primary controls; expand over time.
- Do not regress Web axe gate.

## Out of scope (for now)

Full WCAG AA certification per stack. Focus on name / role / state for primary interactive components.
